## 基础描述

一个专门用来转换含有LaTex语句的MarkDown文件为提供的CSS样式的HTML文件Python应用程序

## 使用介绍

目前该程序支持的功能如下

1. 提供功能尚未健全的CSS文件便于直接转化.
2. 支持将 `$` 与 `$$` 包裹的 `LaTex` 语言通过 `KaTex` 扩展渲染至HTML文件.
3. 允许将特殊语法双横线转义为HTML内的双横线
4. 允许将以`![图例](link)`插入的`SVG`图像直接转化为源码插入HTML.
